# WEBSITE LITERASI DIGITAL

## Deskripsi
Website Literasi Digital merupakan proyek pembelajaran berbasis WordPress yang digunakan untuk mempublikasikan artikel, informasi, dan edukasi mengenai literasi digital.

## Tujuan
Meningkatkan pemahaman masyarakat mengenai penggunaan teknologi dan internet secara bijak, aman, dan bertanggung jawab.

## Teknologi yang Digunakan
- WordPress
- PHP
- MySQL / MariaDB
- XAMPP
- Git
- GitHub

## Fitur Website
- Publikasi artikel literasi digital
- Kategori artikel
- Tag artikel
- Gambar unggulan
- Halaman informasi

## Cara Menjalankan Website
1. Jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Simpan folder website di `C:\xampp\htdocs\literasi`.
4. Buat database melalui phpMyAdmin.
5. Import database website.
6. Atur konfigurasi database pada `wp-config.php` di komputer lokal.
7. Buka `http://localhost/literasi`.
